# 🚙 ოფროუდ წნევა — საბურავის წნევის კალკულატორი

ვებ აპლიკაცია ოფროუდერებისთვის. ირჩევ საბურავის/დისკის ზომას, ავტომობილს, დატვირთვას და
გზის საფარს — აპლიკაცია გეუბნება რამდენი **BAR** და **PSI** უნდა გქონდეს წინა და უკანა საბურავებში.

## შესაძლებლობები

- საბურავის ზომა **მეტრულ** (265/70 R16) ან **ინჩურ** (33x12.5 R15) ფორმატში + პოპულარული ზომები
- საბურავის გეომეტრია: დიამეტრი, გვერდითი კედელი, ბრუნი/კმ, ჰაერის მოცულობა
- ავტომობილის მასა, დამატებითი ტვირთი, საბურავის ტიპი (SUV / LT), ბიდლოკი
- მწარმოებლის (ქარხნული) წნევის შეყვანის შესაძლებლობა
- საფარები: ასფალტი, ყინული, ხრეში, მიწის/ტყის გზა, ტალახი, თოვლი, ღრმა თოვლი, ქვიშა, ქვები/კლდე
- ცალ-ცალკე **წინა და უკანა** ღერძის წნევა, დიაპაზონი, მაქსიმალური სიჩქარე, რჩევები და გაფრთხილებები
- ცხრილი ყველა საფარისთვის ერთად (სქრინისთვის გზაში)
- BAR ⇄ PSI კონვერტერი
- **პრესეტები** — შეინახე შენი მანქანა/საბურავი სახელით, ერთი დაჭერით ჩატვირთე ან წაშალე
- პარამეტრები ინახება ბრაუზერში, მუშაობს ტელეფონზეც, ინტერნეტის გარეშეც

## როგორ გავუშვა

აპლიკაციას არ სჭირდება ინსტალაცია ან ბილდი — ეს არის უბრალო HTML/CSS/JS.

### ვარიანტი 1 — უმარტივესი
ჩამოტვირთე პროექტი და ორჯერ დააჭირე ფაილს **`index.html`** — გაიხსნება ბრაუზერში.

### ვარიანტი 2 — ლოკალური სერვერი (რომ ტელეფონიდანაც გახსნა)
```bash
git clone https://github.com/chipson-git/Tirepreasure.git
cd Tirepreasure

# Python-ით:
python3 -m http.server 8080
# ან Node.js-ით:
npm start
```
შემდეგ გახსენი ბრაუზერში: <http://localhost:8080>

ტელეფონიდან გასახსნელად (იგივე Wi-Fi ქსელში) გამოიყენე კომპიუტერის IP მისამართი,
მაგალითად `http://192.168.1.10:8080`.

### ვარიანტი 3 — ინტერნეტში უფასოდ (GitHub Pages)
1. GitHub-ზე გახსენი რეპოზიტორი → **Settings** → **Pages**
2. **Source**: `Deploy from a branch`, აირჩიე ბრენჩი და ფოლდერი `/ (root)` → **Save**
3. რამდენიმე წუთში აპლიკაცია ხელმისაწვდომი იქნება მისამართზე
   `https://chipson-git.github.io/Tirepreasure/`

### ტესტები
```bash
npm test      # ან: node tests/calc.test.js
```

## როგორ ითვლის

1. **გზის წნევა** — ერთ საბურავზე მოსული დატვირთვისა (მასა + ტვირთი, წინა/უკანა განაწილებით)
   და საბურავის ჰაერის მოცულობის მიხედვით (საორიენტაციოდ 265/70 R16, 550 კგ/საბურავი ≈ 2.3 bar).
   LT საბურავებს +10% ემატება. თუ მწარმოებლის წნევას შეიყვან, გამოიყენება ის.
2. **საფარის კოეფიციენტი** — მაგ. ხრეში ≈ 85%, მიწა ≈ 75%, ტალახი ≈ 58%, ქვიშა ≈ 45%, ღრმა თოვლი ≈ 42%.
3. **დაბალი პროფილი** (მცირე გვერდითი კედელი) — წნევის დაწევა რბილდება დისკის დასაცავად.
4. **უსაფრთხო მინიმუმი** — ბიდლოკის გარეშე 15 psi (LT: 12 psi), ბიდლოკით 6 psi.

ფორმულები და კოეფიციენტები არის `js/calc.js`-ში — მარტივად შეგიძლია შეცვალო.
